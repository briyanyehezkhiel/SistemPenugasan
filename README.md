# Sistem Penugasan Pegawai

Aplikasi desktop untuk membantu pengelolaan penugasan pegawai berdasarkan kegiatan, periode, anggaran, komposisi pegawai, dan kalender penugasan.

## Fitur

- Data pegawai
- Import data pegawai dari Excel
- Tambah, edit, nonaktifkan, aktifkan kembali, dan hapus permanen pegawai
- Pengelolaan kegiatan
- Penanggung Jawab (PJ)
- Penentuan pegawai berdasarkan anggaran
- Komposisi pegawai berdasarkan golongan
- Kalender penugasan
- Pencegahan penugasan pada kegiatan berbeda di hari yang sama
- Rekap penugasan bulanan
- Export data ke Excel

## Teknologi

- Python
- Tkinter
- SQLite
- OpenPyXL
