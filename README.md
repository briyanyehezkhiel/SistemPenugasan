# Sistem Penugasan Pegawai

Aplikasi desktop untuk membantu pengelolaan penugasan pegawai berdasarkan kegiatan, periode, anggaran, komposisi pegawai, dan kalender penugasan.

## 📥 Download

Versi aplikasi yang siap digunakan dapat diunduh melalui:

**[Download Sistem Penugasan Pegawai v1.0.0](../../releases/latest)**

Installer yang tersedia:

`SistemPenugasan-Setup-v1.0.0.exe`

## ✨ Fitur

- 👥 Pengelolaan data pegawai
- 📊 Import data pegawai dari Excel
- ✏️ Tambah, edit, nonaktifkan, aktifkan kembali, dan hapus permanen pegawai
- 📋 Pengelolaan kegiatan
- 👤 Penanggung Jawab (PJ)
- 💰 Penentuan pegawai berdasarkan anggaran
- ⚙️ Penentuan komposisi pegawai berdasarkan golongan
- 📅 Kalender penugasan
- 🚫 Pencegahan penugasan pada kegiatan berbeda di hari yang sama
- 📈 Rekap penugasan bulanan
- 📤 Export data ke Excel

## 🛠️ Teknologi

- **Python**
- **Tkinter**
- **SQLite**
- **OpenPyXL**
- **PyInstaller**
- **Inno Setup**

## 💻 Instalasi

1. Buka halaman [Releases](../../releases).
2. Pilih versi terbaru.
3. Download file installer `.exe`.
4. Jalankan installer.
5. Ikuti proses instalasi sampai selesai.
6. Jalankan **Sistem Penugasan Pegawai** melalui shortcut yang dibuat oleh installer.

## 🗃️ Data Aplikasi

Data aplikasi disimpan secara lokal pada komputer pengguna.

Database tidak disimpan di dalam folder instalasi aplikasi sehingga data pengguna dapat tetap dipertahankan ketika aplikasi diperbarui ke versi berikutnya.
